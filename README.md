MediCare Plus es un proyecto académico de desarrollo web orientado a la construcción de una landing page para un consultorio médico ficticio. Su propósito es presentar información institucional, comunicar los servicios de atención y ofrecer una experiencia de navegación clara, adaptable a distintos dispositivos y accesible para los usuarios. El proyecto se desarrolla en el contexto de la actividad de formación sobre desarrollo asistido por inteligencia artificial (IA) y Vibe Coding.

El Vibe Coding se aborda como un proceso de dirección técnica en el que el aprendiz define requisitos, formula instrucciones para herramientas de IA, revisa el código generado, identifica errores y solicita correcciones. Por tanto, la IA funciona como apoyo para acelerar tareas de diseño y programación, mientras que las decisiones de arquitectura, la validación y la comprensión del resultado siguen siendo responsabilidad del desarrollador.

Esta documentación describe el propósito, alcance, arquitectura, herramientas, flujo de ejecución y criterios de validación de MediCare Plus. También diferencia los elementos definidos para el proyecto de las funcionalidades que deben implementarse y comprobarse durante las siguientes etapas, evitando presentar como terminadas características que aún están pendientes.
